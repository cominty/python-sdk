# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report privately via GitHub's
[security advisories](https://github.com/cominty/python-sdk/security/advisories/new),
or email **security@cominty.com**.

We aim to acknowledge reports within 3 business days and will keep you informed
of remediation progress. Please include steps to reproduce and the affected
SDK version where possible.

## Supported versions

Security fixes are applied to the latest released version on PyPI.
